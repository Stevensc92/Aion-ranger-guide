# Macro

!!! info
    This is the latest version of the macro I use on Taiwan and plan to use on Global. It uses **4 Stigmas** to better reflect the limits we'll have on Global.

    The setup combines the in-game configurable macro with an external macro created using Logitech mouse software.

!!! warning "Macro may change"
    This macro may change as I play on Global, where the ping should be much more manageable.

!!! info "Key bindings"
    In the external Logitech macro, the **$** key is the key I assigned to the in-game macro and is configured as a hold.

    The **R** key is the key assigned to the main skill (in this case, **Snipe** for Ranger) and is also configured as a hold.

    The **"** key is assigned to the key bound to **Gale Arrow** and the other skills in that column. It is configured to repeat continuously. You may notice that this key is already used in the in-game macro. After testing, I found that using it in both macros works better because it ensures the skills in that column are used as soon as they become available.
